How to Read This
Interpretation guide for the thesis defence
Local explanation — the top chart explains this one URL. A long red bar means that feature strongly increased the phishing probability; a green bar decreased it.
Global importance — the second chart shows which features matter most across the whole training set. Path length, token count and HTTPS usage dominate the model.
Additivity — the base value is the average model output (~50%). Adding all SHAP contributions reproduces the exact phishing probability shown in the summary card.
Verification layer — the rule-based risk indicators on the scanner page are independent of SHAP and provide human-readable evidence alongside the model.
